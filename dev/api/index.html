The module

ClusterAlgebras.ClusterAlgebras — Module
ClusterAlgebras

Exact computation with cluster algebras: quivers, seeds and mutation, coefficients, finite-type classification, exchange graphs, green sequences, friezes, and the cluster structures on Grassmannians.

Cluster variables live in Frac(ZZ[x₁,…,xₙ]), so every result is exact. Quivers and seeds are immutable: mutate returns a new object.

Entry points

  • Quiver - build a quiver from a B-matrix, a Dynkin type (Quiver(:A, 3)), a type string (Quiver("D4")) or an edge list; mutate mutates it.
  • Seed - a quiver together with its cluster; mutate(s, k) or mutate(s, [1,2,1]).
  • extend / extend_geometric - attach principal or geometric coefficients, giving cmatrix, gmatrix, f_polynomial and separation_formula.
  • is_finite_type, cartan_type, n_cluster_variables - classification and counting.
  • mutation_class, exchange_graph - the combinatorics of all seeds.
  • maximal_green_sequences, dt_transformation - green sequences and the Donaldson–Thomas transformation.
  • grassmannian, symbol_alphabet - Grassmannian seeds and their symbol alphabets.

Plotting (plot_quiver, plot_exchange_graph, plot_frieze, …) lives in package extensions: load Graphs, GraphMakie and a Makie backend to enable it.

The manual is at https://benedikt-nagler.github.io/ClusterAlgebras.jl/.
