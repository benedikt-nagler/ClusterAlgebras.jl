Mutation classes and exchange graphs

Enumeration of the mutation class of a quiver, up to isomorphism, and the exchange graph it spans.

ClusterAlgebras.ExchangeGraph — Type
ExchangeGraph

Result of a seed-level BFS starting from a Seed. Vertices are distinct seeds (identified by their ordered d-vector tuple); adj[i][k] is the index of the seed obtained by mutating seeds[i] at mutable vertex k.

truncated is true when the BFS was stopped early because the number of distinct seeds reached max_seeds.

For finite-type cluster algebras the BFS terminates and length(eg) equals the number of clusters. Deduplication uses ordered d-vector tuples, which correctly separates all seeds for finite types (d-vector conjecture) and is safe up to the cutoff for infinite types.

source
ClusterAlgebras.MutationClass — Type
MutationClass

Result of a quiver-level BFS starting from a Quiver. Vertices are distinct exchange matrices reachable by mutation; adj[i][k] is the index of the quiver obtained by mutating quivers[i] at mutable vertex k.

When produced with up_to_isomorphism = true, vertices are quiver isomorphism classes rather than labeled exchange matrices: each entry of quivers is the first-seen representative of its class, and adj is the unlabeled mutation graph built from those stored representatives (mutating a representative at k may land on a relabeling of an already-seen class).

truncated is true when the BFS was stopped early because the number of distinct vertices reached max_quivers.

source
ClusterAlgebras.exchange_graph — Method
exchange_graph(s::Seed; max_seeds::Int = 1000) → ExchangeGraph

BFS over all seeds reachable from s by single mutations, deduplicating by ordered d-vector tuple. Stops early (truncated = true) once max_seeds distinct seeds have been found.

For finite-type cluster algebras length(exchange_graph(s)) equals the number of clusters (e.g. 5 for A₂, 14 for A₃, 50 for D₄).

ClusterAlgebras.is_truncated — Method
is_truncated(x) → Bool

Whether the search that produced x stopped at its seed or quiver cap instead of exhausting the class.

Defined for MutationClass, ExchangeGraph, ClusterFan and ClusterComplex. A truncated result is a piece of the object, so counts read off it are lower bounds and the enumerative identities do not apply. Raise max_quivers or max_seeds to finish the search, or use a finite-type quiver.

source
ClusterAlgebras.mutation_class — Method
mutation_class(q::Quiver; max_quivers::Int = 1000,
               up_to_isomorphism::Bool = false) → MutationClass

BFS over all quivers mutation-equivalent to q. Stops early (truncated = true) once max_quivers distinct vertices have been found.

By default vertices are deduplicated by exact exchange-matrix equality, so vertex-relabeled copies of the same quiver count as distinct vertices. With up_to_isomorphism = true the dedup key is the isomorphism invariant (canonical_form(qi).B, qi.d) (matching is_isomorphic), so each isomorphism class is stored once - this gives literature-consistent class sizes. The stored representative is the first-seen labeled quiver, so mc[1] == q, and adj is then the unlabeled mutation graph (see MutationClass).

For mutation-finite types (e.g. all finite Dynkin types) the BFS terminates naturally. For mutation-infinite types the max_quivers cutoff prevents the search from hanging.

ClusterAlgebras.ClusterComplex — Type
ClusterComplex

The cluster complex: vertices are cluster variables, facets are clusters, and the faces are the subsets of pairwise compatible cluster variables.

Fields vertices (one d-vector per cluster variable), facets (sorted indices into vertices) and truncated. Build one with cluster_complex; its f_vector counts the faces by dimension. Immutable.

source
ClusterAlgebras.ClusterFan — Type
ClusterFan

The g-vector fan of a cluster algebra: one ray per cluster variable, one maximal cone per cluster.

Fields rays (g-vectors), cones (sorted indices into rays, one entry per cluster) and truncated. In finite type the fan is complete and is the normal fan of the generalized associahedron, so is_complete holds; in infinite type only the part reached within max_seeds seeds is present and truncated is true. Build one with g_vector_fan. Immutable.

source
ClusterAlgebras.cluster_complex — Method
cluster_complex(s::Seed; max_seeds::Int = 1000) → ClusterComplex

The cluster complex of s, with cluster variables as vertices and clusters as facets.

Vertices are labelled by d-vector. For a finite-type seed the complex is the boundary complex of the generalized associahedron; otherwise it is truncated at max_seeds seeds, and f_vector then undercounts.

julia> cc = cluster_complex(Quiver(:A, 3))
ClusterComplex: 9 vertices, 14 facets, rank 3

julia> f_vector(cc)
4-element Vector{Int64}:
  1
  9
 21
 14

ClusterAlgebras.g_vector_fan — Method
g_vector_fan(s::Seed; max_seeds::Int = 1000) → ClusterFan

The g-vector fan of s: the g-vectors of all cluster variables as rays, grouped into one maximal cone per cluster.

A TrivialCoefficients seed is extended to principal coefficients first, since g-vectors are defined there. Distinct cluster variables have distinct g-vectors (Gross-Hacking-Keel-Kontsevich), so the rays are in bijection with the cluster variables and the cones with the clusters. Rays are read off with respect to the initial seed of s; see the ledger at the top of src/cluster_fan.jl.

For a finite-type seed this is the complete normal fan of the generalized associahedron. Otherwise the exchange graph is explored only to max_seeds seeds and the result is flagged by is_truncated, which makes it a piece of the fan and not the fan.

julia> fan = g_vector_fan(Quiver(:A, 2))
ClusterFan: 5 rays, 5 maximal cones, rank 2

julia> length(rays(fan)) == n_cluster_variables(Quiver(:A, 2))
true

julia> is_complete(fan)
true
source
ClusterAlgebras.is_complete — Method
is_complete(f::ClusterFan) → Bool

Whether every wall of f is shared by exactly two maximal cones, the combinatorial criterion for a complete simplicial fan.

Cluster fans are simplicial, so for an untruncated fan this is completeness, and it is equivalent to the exchange graph being regular of degree the rank. A truncated fan is never complete. The test is combinatorial: it does not check that the cones cover $\mathbb{R}^n$ geometrically.

ClusterAlgebras.ForklessPart — Type
ForklessPart

Result of a forkless_part or pre_forkless_part search.

quivers holds the members - the non-forks (resp. non-forks and non-pre-forks) of the labeled mutation class, each a distinct exchange matrix. adj[i][k] is the index of the quiver obtained by mutating quivers[i] at vertex k, or 0 when that mutation leaves the part. kind is :fork or :pre_fork, recording which boundary was used, and truncated is true when the search stopped at max_quivers instead of closing.

source
ClusterAlgebras.forkless_part — Method
forkless_part(q::Quiver; max_quivers::Int = 10_000) → ForklessPart

The forkless part of the labeled mutation class of q: every quiver mutation-equivalent to q that is not a fork (Ervin 2023, Definition 3.1).

Forks are boundary rather than members. Warkentin's Tree Lemma makes the search exact: everything behind a fork, except through its point of return, is again a fork, so the returned part is complete whenever the search closes.

The search closes for a quiver with a finite forkless part - which includes every mutation-finite quiver, since a mutation-finite connected quiver is mutation-equivalent to no fork at all - and runs to max_quivers otherwise, when the result is a truncated piece and is_truncated is true. The same holds when an exact mutation exceeds the stored integer type. Use has_finite_forkless_part for the yes/undecided verdict.

Example

julia> using ClusterAlgebras

julia> fp = forkless_part(Quiver(:A, 3));

julia> length(fp), is_truncated(fp)
(14, false)
source
ClusterAlgebras.has_finite_forkless_part — Method
has_finite_forkless_part(q::Quiver; max_quivers::Int = 10_000)
    → Union{Bool, Nothing}

true when the forkless part of q closes within max_quivers, nothing when the budget runs out first.

Never false: no finite search certifies an infinite forkless part, so the undecided verdict is reported as nothing rather than folded into false. Raise max_quivers to push the boundary.

Having a finite forkless part is hereditary and invariant under mutation (Ervin 2023, Corollary 3.6), so a true here also settles every full subquiver, and a nothing says nothing about them.

Example

julia> using ClusterAlgebras

julia> has_finite_forkless_part(Quiver(:A, 3))
true

has_finite_pre_forkless_part(q::Quiver; max_quivers::Int = 10_000)

true when the pre-forkless part of q closes within max_quivers, nothing when the budget runs out first, with the same asymmetry as has_finite_forkless_part.

ClusterAlgebras.point_of_return — Method
point_of_return(q::Quiver) → Union{Int, Nothing}

The point of return of q when q is a fork, and nothing otherwise.

A fork (Warkentin 2014, Definition 2.1) is an abundant quiver that is not acyclic and has a vertex r such that every arrow between the in-neighbours and out-neighbours of r runs from an out-neighbour j back to an in-neighbour i, with B[j,i] strictly larger than both B[i,r] and B[r,j], and such that the in-neighbours and out-neighbours of r each induce an acyclic subquiver. The point of return is unique.

Mutating a fork anywhere except at r gives another fork with strictly more arrows, so r is the only direction in which the mutation class does not grow.

Example

julia> using ClusterAlgebras

julia> point_of_return(Quiver([0 2 -3; -2 0 2; 3 -2 0]))
2

julia> point_of_return(Quiver([0 2 -2; -2 0 2; 2 -2 0]))  # the Markov quiver

ClusterAlgebras.pre_fork_vertices — Method
pre_fork_vertices(q::Quiver) → Union{NamedTuple, Nothing}

The distinguished vertices (r, k, k′) when q is a pre-fork, and nothing otherwise.

A pre-fork (Warkentin 2014, Definition 3.7) is a quiver with two vertices k and k′ such that deleting either one leaves a fork, both with the same point of return r, and such that no third vertex is a stopover: no i carries arrows k′ → i → k or k → i → k′. Pre-forks generalise forks and bound the mutation class the same way, which is what makes the pre-forkless part a coarser, and more often finite, invariant than the forkless part.

k < k′ in the returned tuple; a quiver can be a pre-fork on several pairs and the first in that order is reported.

Example

julia> using ClusterAlgebras

julia> pre_fork_vertices(Quiver(:A, 3))

ClusterAlgebras.pre_forkless_part — Method
pre_forkless_part(q::Quiver; max_quivers::Int = 10_000) → ForklessPart

The pre-forkless part of the labeled mutation class of q: every quiver mutation-equivalent to q that is neither a fork nor a pre-fork (Ervin 2023, Definition 5.1).

Pre-forks bound larger regions than forks, so this part is contained in the forkless part and closes strictly more often - Warkentin's (a,b) box quivers with a, b ≥ 2 have a finite pre-forkless part and an infinite forkless part. See forkless_part for the search's semantics.
